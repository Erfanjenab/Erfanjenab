### 🖐️ Hand Gesture Number Classifier

A CNN-based image classification model designed to recognize hand gestures representing numbers from 0 to 9.

**Technologies:** Python, TensorFlow, Keras, CNN

🔗 [View Repository](https://github.com/Erfanjenab/Hand-Gesture-Number-Classifier)

### 🐱 Cat & Dog Classifier

An image classification project using Transfer Learning with the pretrained EfficientNetB0 architecture to distinguish between cats and dogs.

**Technologies:** Python, TensorFlow, Keras, EfficientNetB0
